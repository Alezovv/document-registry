**DocumentRegistry** — современное настольное портативное Windows-приложение для автоматизированного учёта, интеллектуального распознавания, контроля исполнения и структурированного хранения входящих и исходящих документов, писем и запросов (ОМВД, ведомства, организации, обращения граждан).

Приложение работает **полностью локально** (offline-first), не требует интернета для распознавания текстов, не передаёт конфиденциальные документы во внешние облачные сервисы и оптимизировано для стабильной работы даже на стандартных офисных компьютерах.

---

## 📌 Основные возможности

### 🤖 1. Интеллектуальный импорт и распознавание (AI / OCR / NER)
* **Автономное OCR-распознавание:** встроенные лёгкие нейросетевые модели PaddleOCR (PP-OCRv5 Mobile ONNX) распознают текст отсканированных PDF и изображений прямо на компьютере пользователя без отправки данных в сеть.
* **Автоматическое извлечение реквизитов (NER + эвристики):**
  * Исходящий номер и дата документа;
  * Наименование заявителя / органа (ОМВД, администрация, прокуратура, ФССП и др.);
  * Предмет / тема запроса;
  * ФИО и контакты исполнителя.
* **Память исправлений парсера:** программа запоминает корректировки, внесённые пользователем, и в следующий раз автоматически подставляет правильные реквизиты для аналогичных документов.
* **Немодальный предпросмотр (Review):** удобный интерфейс быстрой проверки и правки распознанных данных с цветными бейджами степени уверенности алгоритма.

### 📋 2. Удобный реестр и работа с данными
* **Компактный реестр:** эргономичный вид таблицы (8–10 видимых строк при стандартных разрешениях) с горизонтальной и вертикальной прокруткой.
* **Мгновенный поиск и фильтры:** быстрый поиск по регистрационным номерам, датам, органам, заявителям, темам и исполнителям.
* **Детекция и подсветка дубликатов:**
  * Анализ точных хэшей файлов (SHA-256);
  * Цифровые отпечатки текста документа (fingerprint);
  * Предупреждение оператора при попытке повторной регистрации уже имеющегося в базе запроса.
* **Статусная модель исполнения:** наглядное отслеживание жизненного цикла запроса («На рассмотрении», «В работе», «Исполнен», «Отклонен», «Просрочен»).
* **Экспорт:** выгрузка реестра и отфильтрованных выборок в форматы Excel (`.xlsx`) и CSV.

### ⚡ 3. Производительность и надёжность
* **Memory Governor (Контроллер памяти):** интеллектуальное ограничение потребления оперативной памяти, позволяющее комфортно работать даже на офисных ПК с 4 ГБ ОЗУ без зависаний и OOM-сбоев.
* **Оптимизированная база SQLite:** постраничная подгрузка данных (Pagination / Lazy Loading), транзакционный режим `WAL` (Write-Ahead Logging) и автоматическая архивация истории правок (лимит до 2000 записей).
* **Поддержка длинных путей Windows (`MAX_PATH > 260`):** прозрачная работа с длинными названиями файлов и глубокой структурой вложенных папок через расширенные пути `\\?\`.

### 🛡️ 4. Безопасность данных и резервное копирование
* **Автоматический pre-update бэкап:** создание проверенного snapshot базы данных и оригиналов документов перед каждым обновлением программы.
* **Резервное копирование по расписанию и вручную:** создание полных архивов с проверкой целостности (`PRAGMA integrity_check`).
* **Корзина документов:** защита от случайного безвозвратного удаления записей и файлов.

### 🔄 5. Бесшовное автообновление и откат (Rollback)
* **Обновление вперёд:** проверка и скачивание актуальных версий из защищённого хранилища без необходимости прав администратора.
* **Двунаправленный откат (Rollback):** уникальная возможность откатиться на любую предыдущую версию с **автоматической адаптацией схемы базы данных** (`downgrade_database`) и сохранением рабочих данных.

## 💻 Системные требования

* **Операционная система:** Windows 10 / Windows 11 (64-bit).
* **Процессор:** 2-ядерный процессор с тактовой частотой от 2.0 ГГц (поддержка инструкций AVX приветствуется).
* **Оперативная память:** от 4 ГБ (рекомендуется 8 ГБ).
* **Место на диске:** ~1 ГБ для программы и моделей + место для хранения базы и сканов документов.
* **Дополнительно:** подключение к интернету требуется **только** для загрузки обновлений программы (все функции распознавания и реестра работают 100% автономно).

## 🚀 Быстрый старт

### Вариант А. Запуск готовой портативной версии (Portable)
1. Скачайте архив релиза `DocumentRegistry_vX.Y.Z_portable.zip`.
2. Распакуйте архив в любую удобную пользовательскую папку (например, `C:\DocumentRegistry` или на Рабочий стол).
3. Запустите `DocumentRegistry.exe`.
4. Приложение готово к работе: база данных и папки для документов будут созданы автоматически внутри каталога программы.

---

### Вариант Б. Запуск из исходного кода (для разработчиков)

1. **Клонирование репозитория:**
   ```bash
   git clone https://github.com/your-org/document-registry.git
   cd document-registry
   ```

2. **Создание и активация виртуального окружения:**
   ```powershell
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   ```

3. **Установка зависимостей:**
   ```powershell
   pip install --upgrade pip
   pip install -r requirements.txt
   ```

4. **Запуск приложения:**
   ```powershell
   python -m app
   ```

5. **Запуск полного набора тестов:**
   ```powershell
   python verify_project.py --full
   ```

## 🛠️ Сборка, релиз и публикация обновлений

Процесс сборки релиза полностью автоматизирован с помощью скрипта `packaging/build.ps1`.

### 1. Подготовка версии
Синхронизируйте номер версии в:
* `app/__init__.py`: `__version__ = "1.28.8"`
* `packaging/build.ps1`: `[string]$Version = "1.28.8"`

### 2. Запуск сборки
```powershell
powershell -ExecutionPolicy Bypass -File .\packaging\build.ps1 -Python ".\.venv\Scripts\python.exe" -Version "1.28.8" -PublishTo "release" -ReleaseNotes "Описание изменений релиза..."
```

Что делает скрипт:
1. Запускает проверку проекта (`verify_project.py --full`) и прогоняет 260+ тестов.
2. Собирает через PyInstaller основной исполняемый файл `DocumentRegistry.exe` и автономный апдейтер `DocumentRegistryUpdater.exe`.
3. Запускает автоматическую самодиагностику замороженного приложения (`--self-check`, `--ocr-self-check`, `--ner-self-check`).
4. Формирует переносимый архив `release/DocumentRegistry_v1.28.8_portable.zip`.
5. Упаковывает пакет обновления `release/DocumentRegistry_1.28.8_update.zip` и рассчитывает его SHA-256.

### 3. Публикация в Google Drive
1. Загрузите файл `release/DocumentRegistry_1.28.8_update.zip` в папку обновлений на Google Диске (*старые zip-файлы не удаляйте для сохранения истории отката*).
2. Скопируйте ссылку общего доступа и извлеките `file_id`.
3. Сформируйте публичный `manifest.json`:
   ```powershell
   powershell -ExecutionPolicy Bypass -File .\packaging\build.ps1 -Version "1.28.8" -ManifestOnly -PublishTo "release" -PackageFileId "<GOOGLE_DRIVE_FILE_ID>" -ReleaseNotes "Описание изменений..."
   ```
4. На Google Диске нажмите правой кнопкой на существующий `manifest.json` $\rightarrow$ **«Управление версиями»** $\rightarrow$ **«Загрузить новую версию»** и выберите локальный `release/manifest.json`.

## 🔒 Безопасность и конфиденциальность

* **100% локальное исполнение:** программа не использует внешние веб-API для обработки документов. Все сканы, распознанные тексты и реквизиты хранятся исключительно на локальном накопителе пользователя.
* **Транзакционность данных:** любые операции с базой защищены журналами упреждающей записи SQLite (WAL). В случае аварийного отключения питания данные не повреждаются.
* **Изолированный установщик:** модуль обновления запускается из временного изолированного каталога, выполняет предварительное резервное копирование и возвращает систему в исходное состояние при любом сбое.
